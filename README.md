## 🚀 Featured Project: Portfolio Live Coding Playground

<div align="center">
  
  [![Portfolio Demo](https://img.shields.io/badge/🎮_Live_Demo-00F5FF?style=for-the-badge)](https://messaoud-hamdi.dev)

**An innovative fullstack portfolio that goes beyond static pages** - featuring live code execution, algorithm visualization, and real-time system monitoring.

### 🎯 Key Features

- **🔥 Live Code Execution**: Run Java, C++, JavaScript, and Python directly in the browser
- **🧪 Algorithm Visualization Lab**: Real-time C++ algorithm execution with step-by-step visualization
- **📊 System Monitoring**: Live metrics display with performance analytics
- **🎨 Cyber Console UI**: Custom-designed terminal aesthetic with matrix rain effects
- **⚡ High Performance**: Redis caching, optimized queries, and efficient data handling

### 🏗️ Technical Architecture

**Backend (Spring Boot):**
- Advanced Spring Boot 3.2 patterns (DI, AOP, JPA, Caching)
- Secure code execution engine with sandboxing
- RESTful API with comprehensive OpenAPI documentation
- Multi-strategy Redis caching for performance
- PostgreSQL with optimized JPA queries
- Real-time WebSocket communication

**Frontend (Next.js):**
- Server-side rendering for SEO optimization
- Monaco Editor integration for syntax highlighting
- Framer Motion animations and smooth transitions
- Responsive design with Tailwind CSS
- Custom console/cyber theme with CSS variables

**DevOps:**
- VPS deployment with CloudPanel (Ubuntu 22.04)
- GitHub Actions CI/CD pipeline
- Nginx reverse proxy with SSL
- SystemD service management
- Docker containerization ready
